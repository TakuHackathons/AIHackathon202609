# CSV取込サンプル

架空の「青葉未来大学」での運用を想定し、項目同士の関係が分かる内容にしています。実在する学生の個人情報は含みません。

## ファイル

| ファイル                    | 内容                               | 件数 |
| --------------------------- | ---------------------------------- | ---: |
| `teachers.csv`              | 授業担当として参照する教員         |    5 |
| `facilities.csv`            | 講義室・図書館・学生支援施設など   |    8 |
| `students.csv`              | 学生番号・性格・配慮事項・検索タグ |   10 |
| `courses-and-schedules.csv` | 授業と曜日・時限による通常時間割   |    8 |
| `resources.csv`             | 学校規則・進路資料・イベント・案内 |   10 |

## 取込手順

1. 管理画面で対象の学校を選択します。
2. `teachers.csv`、`facilities.csv`、`students.csv`をそれぞれの管理画面から取り込みます。
3. 授業・時間割画面で、学期名が`2026年度 前期`の学期を登録します。
4. 1時限から5時限までを登録します。時間の例は、1時限`09:00–10:30`、2時限`10:40–12:10`、3時限`13:00–14:30`、4時限`14:40–16:10`、5時限`16:20–17:50`です。
5. `courses-and-schedules.csv`を授業・時間割画面から取り込みます。
6. `resources.csv`を資料画面から取り込みます。

授業CSVの`teacher_username`と`facility_name`は、教員CSVと施設CSVの値に合わせています。オンライン授業の行では`facility_name`を空にし、`location_note`に参加方法を記載しています。

教員CSVのメールアドレスはサンプル用の予約ドメインです。実際の運用では学校のメールアドレスへ置き換えてください。新規教員のログイン用パスワードは取込結果に表示されます。
